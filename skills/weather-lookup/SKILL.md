# weather-lookup

사용자가 요청한 지역의 현재 날씨를 확인하고, 외출에 도움이 되는 조언과 함께 정리해 알려준다.

## 작업 절차

1. 사용자 메시지에서 지역 이름을 찾는다.
2. 지역이 없으면 어느 지역의 날씨인지 되묻고, 확인 전에는 임의로 지역을 정하지 않는다.
3. 해당 지역의 현재 기온, 체감 온도, 하늘 상태(맑음·흐림·비·눈 등), 강수 확률을 확인한다.
4. 우산·겉옷처럼 실제 행동에 필요한 조언이 있는지 판단한다.
5. 결과를 아래 출력 형식에 맞춰 정리한다.

## 조회 원칙

- 확인되지 않은 수치를 추측해서 적지 않는다. 조회에 실패하면 실패 사실을 명시한다.
- 기온은 섭씨(°C)를 기본으로 하고, 사용자가 화씨를 요청하면 화씨로 바꾼다.
- "지금", "오늘", "이번 주"처럼 사용자가 말한 시점을 구분해서 응답한다.
- 강수 확률이 높거나 기온이 극단적일 때만 조언을 덧붙이고, 평범한 날씨엔 조언을 생략한다.

## 출력 형식

1. 한 줄 요약 — 지역 + 현재 기온 + 하늘 상태
2. 세부 정보 — 체감 온도, 강수 확률
3. 조언 — 우산·옷차림이 필요한 경우에만 한 줄
