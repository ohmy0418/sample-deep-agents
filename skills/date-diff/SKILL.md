# date-diff

두 날짜 사이가 며칠인지, 그리고 그 날짜가 무슨 요일인지 계산해 알려준다. 날짜 계산은 직접 하지 않고, 반드시 제공된 스크립트를 실행해서 그 결과를 사용한다.

## 작업 절차

1. 사용자 메시지에서 날짜 두 개를 찾아 `YYYY-MM-DD` 형식으로 정리한다. 날짜가 하나뿐이면 나머지 하나가 언제인지 되묻는다.
2. 아래 명령을 그대로 사용해 스크립트를 실행한다. 경로 앞에 슬래시(/)를 붙이지 않는다.
   - 실행 형식: `python skills/date-diff/scripts/date_diff.py <시작날짜> <종료날짜>`
   - 예: `python skills/date-diff/scripts/date_diff.py 2026-01-01 2026-09-09`
3. 스크립트가 출력한 결과(`DAYS=...`, `WEEKDAY=...`)를 그대로 읽는다.
4. 결과를 아래 출력 형식에 맞춰 사용자에게 알려준다.

## 원칙

- 일수와 요일은 반드시 스크립트 실행 결과를 근거로 답한다. 직접 계산하거나 추측하지 않는다.
- `DAYS` 값이 음수이면 종료날짜가 시작날짜보다 과거라는 뜻이다. 이 경우 "지났다"로 해석해 알린다.
- 스크립트를 실행할 때 경로는 반드시 `skills/`로 시작하는 상대 경로를 쓴다. read_file이나 ls에 보이는 `/skills/...`(앞에 슬래시가 있는 경로)를 셸 명령에 그대로 넣지 않는다.
- 스크립트 실행이 실패하면 실패 사실을 그대로 알린다.

## 출력 형식

1. 계산 결과 — "시작날짜부터 종료날짜까지 N일"
2. 요일 — 종료날짜의 요일
3. 근거 — 스크립트 출력값(`DAYS=...`, `WEEKDAY=...`)
