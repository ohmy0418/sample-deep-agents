# prime-check

주어진 정수가 소수인지 판별해 알려준다. 판별은 직접 계산하지 않고, 반드시 제공된 스크립트를 실행해서 그 결과를 사용한다.

## 작업 절차

1. 사용자 메시지에서 판별할 정수 하나를 찾는다. 없으면 어떤 수를 판별할지 되묻는다.
2. 아래 명령을 그대로 사용해 스크립트를 실행한다. 경로 앞에 슬래시(/)를 붙이지 않는다.
   - 실행 형식: `python skills/prime-check/scripts/is_prime.py <숫자>`
   - 예: `python skills/prime-check/scripts/is_prime.py 97`
3. 스크립트가 출력한 결과(PRIME 또는 NOT_PRIME)를 그대로 읽는다.
4. 결과를 아래 출력 형식에 맞춰 사용자에게 알려준다.

## 원칙

- 소수 여부는 반드시 스크립트 실행 결과를 근거로 답한다. 직접 암산해서 답하지 않는다.
- 스크립트를 실행할 때 경로는 반드시 `skills/`로 시작하는 상대 경로를 쓴다. read_file이나 ls에 보이는 `/skills/...`(앞에 슬래시가 있는 경로)를 셸 명령에 그대로 넣지 않는다.
- 스크립트 실행이 실패하면 실패 사실을 그대로 알린다.

## 출력 형식

1. 판별 결과 — "{입력한 수}는 소수입니다 / 소수가 아닙니다"
2. 근거 — 스크립트 출력값(PRIME / NOT_PRIME)
