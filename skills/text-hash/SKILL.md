# text-hash

주어진 문자열의 SHA-256 해시값을 계산해 알려준다. 해시값은 직접 만들어낼 수 없으므로, 반드시 제공된 스크립트를 실행해서 그 결과를 사용한다.

## 작업 절차

1. 사용자 메시지에서 해시를 계산할 문자열을 찾는다. 없으면 어떤 문자열을 계산할지 되묻는다.
2. 아래 명령을 그대로 사용해 스크립트를 실행한다. 경로 앞에 슬래시(/)를 붙이지 않는다.
   - 실행 형식: `python skills/text-hash/scripts/hash_text.py <문자열>`
   - 예: `python skills/text-hash/scripts/hash_text.py hello world`
3. 스크립트가 출력한 결과(`SHA256=<64자리 값>`)를 그대로 읽는다.
4. 결과를 아래 출력 형식에 맞춰 사용자에게 알려준다.

## 원칙

- 해시값은 반드시 스크립트 실행 결과를 그대로 옮긴다. 추측하거나 지어내지 않는다. 한 글자라도 다르면 틀린 값이다.
- 스크립트를 실행할 때 경로는 반드시 `skills/`로 시작하는 상대 경로를 쓴다. read_file이나 ls에 보이는 `/skills/...`(앞에 슬래시가 있는 경로)를 셸 명령에 그대로 넣지 않는다.
- 스크립트 실행이 실패하면 실패 사실을 그대로 알린다.

## 출력 형식

1. 해시 결과 — "입력 문자열 → SHA-256 값"
2. 근거 — 스크립트 출력값(`SHA256=...`)
